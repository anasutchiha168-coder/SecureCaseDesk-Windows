## رابعاً: الـ APK

لم يُسجَّل APK بعد: `python3 scripts/final-report.py apk "تشغيل Actions رقم N" [ملف.apk]`

**الاسترجاع:** GitHub ← Actions ← «Android APK (local release candidate)» ← Run workflow (profile: preview) ← بعد النجاح Artifact باسم `SecureCaseDesk-apk-preview-run<N>` (فيه APK و`.sha256` و`build-info.txt`، يُحفظ 30 يوماً، والمستودع يجب أن يكون Private).
**التحقق:** `sha256sum -c SecureCaseDesk-preview-run<N>.apk.sha256` ثم التثبيت (`adb install -r` أو تفعيل المصادر غير المعروفة).
**أسرار:** `EXPO_TOKEN` فقط في GitHub Secrets؛ مفتاح SQLCipher يُولَّد على الجهاز ولا يوجد في CI.
